Princípios

Uma ação por tela

Cada tela tem um botão principal, preto. O azul fica para o que registra algo novo e para foco.

Cartão só onde há decisão

Listas e tabelas ficam soltas no fundo, separadas por linhas finas. Cartão e painel entram quando alguém precisa agir.

Status com forma e palavra

Normal é círculo, atenção é triângulo, crítico é quadrado. Sempre com o texto, nunca só com cor.
