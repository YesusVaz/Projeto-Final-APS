# Desenho das telas (referencia)

Fragmentos HTML exportados do desenho feito no Claude. Servem so pra ver estrutura, textos e dados de exemplo.

- `telas/d-*.html`: uma tela por arquivo. `d-m-*` sao as versoes de celular (390 x 844).
- `estilo-base.css`: as classes que os fragmentos usam (btn, badge, li, tbl, sheet...).
- Marcas como `{{toggleMenu}}` eram do editor de desenho. Ignore.
- Nao copie o HTML. No app, monte as telas com os componentes de `frontend/src/ui`.
